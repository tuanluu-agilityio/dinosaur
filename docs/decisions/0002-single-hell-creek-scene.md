# 0002 — One scientifically accurate Hell Creek scene

- **Status:** Accepted
- **Date:** 2026-10-31
- **Decided by:** user

## Context
Mixing dinosaurs from different periods would look like a movie, not science (spec §6). Other periods may come later.

## Decision
- One scene: North America, late Maastrichtian (~68–66 Ma), Hell Creek–type ecosystem.
- Species: *Tyrannosaurus rex*, *Triceratops horridus*, *Ankylosaurus magniventris*, *Edmontosaurus annectens*, *Pachycephalosaurus wyomingensis*. Only species that co-existed there may appear.
- Flora: ferns, cycads, conifers (e.g. Metasequoia), early angiosperm shrubs. **No grass.**
- Code may be structured so another scene can be added later, but no scene switcher is built now.

## Consequences
Adding a species from another period/place is forbidden without a new ADR and a new scene.
