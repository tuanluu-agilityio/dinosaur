# Rubric — species content (fact-checker)

Grade every line PASS / FAIL. Check claims against the cited sources yourself (open them); do not trust the writer's summary.

## Accuracy
| # | Check |
|---|---|
| C1 | Every factual claim (size, mass, age, behaviour, discovery) is supported by one of the listed `sources` |
| C2 | ≥ 4 sources; at least 2 peer-reviewed papers or museum pages; no fan wikis, no AI-generated pages |
| C3 | Numbers are ranges with units and match sources (`lengthM`, `massT`, `periodMa`); `periodMa` within 68–66 Ma overlap for this scene |
| C4 | Contested topics are phrased as contested (e.g. T. rex lips, integument, top speed; Pachycephalosaurus head-butting) and listed in `contested[]` |
| C5 | No outdated claims presented as fact (e.g. T. rex as pure scavenger, Brontosaurus-style swamp myths, "Triceratops used frill only for defence") |

## Language
| # | Check |
|---|---|
| L1 | `vi` and `en` say the same thing (no missing sentence in either) |
| L2 | Vietnamese reads naturally (not word-for-word translation), correct diacritics |
| L3 | Terminology follows the glossary below; scientific names in italics in UI, never translated |
| L4 | Each section 120–200 words; suitable for adult enthusiasts, no jargon without a short explanation |
